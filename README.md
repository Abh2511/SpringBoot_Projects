Student Management System

A simple and responsive Student Management System built using Spring Boot, Thymeleaf, Spring Data JPA, and MySQL. 
This project helps manage student records with CRUD operations such as adding, updating, viewing, and deleting 
student details.

🚀 Features
Add new students
View student list
Update student details
Delete student records
Form validation using Spring Validation
Responsive UI with Thymeleaf templates
Database integration with MySQL.

🛠️ Technologies Used
Java 
Spring Boot
Spring MVC
Spring Data JPA
Thymeleaf
MySQL
Maven
Lombok
